# RahaWRT

Open-source Persian/English network management for OpenWrt.

## Status

Early development. No installable release or verified router support yet. Initial physical test target: x86 with PassWall2. Architecture discovery is not a compatibility certification.

## Planned modules

- PassWall2 per-device node selection and direct/VPN schedules
- Per-account upload/download limits and persistent usage quotas
- Parental domain filtering and access schedules
- Captive portal, vouchers and receipt/accounting API
- OpenVPN, WireGuard, L2TP and OpenConnect adapters
- Persian RTL and English UI at `/wrt/`

See `docs/architectures.md` for official architecture inventories and validation boundaries.
